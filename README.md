# English for Kids 10+ — Grammar Roadmap

(in process)

A free, self-paced English grammar course for kids 10+ (A2 → Pre-B1).
30 tracks in 4 levels, each with a grammar lesson and a task pack.

**Open the course:** https://vbforge.github.io/english-for-kids-beginner/

## What's inside

| Levels | Tracks |
|---|---|
| 🌱 Beginner | 1–6 |
| ⭐ Elementary | 7–15 |
| 🚀 Pre-Intermediate | 16–24 |
| 🏆 Intermediate | 25–30 |

- `index.html` — the roadmap (start here)
- `track-N.html` — lesson: grammar rule, examples, vocabulary, quick practice
- `track-N-tasks.html` — tasks: reading, listening, speaking, writing
- `review-1.html … review-6.html` — review units between levels
- `tracks-N-N-test.html` — tests for the tracks by Units

## How to use

1. Follow the tracks in order, 1–2 weeks per track (15–20 minutes a session).
2. Do the lesson **and** the tasks in the same week.
3. Tick a track as done only when the child uses the structures confidently in real speech.

Progress ticks and badges are saved in the browser on that device only (they do not sync between devices).

## For the maintainer
